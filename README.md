# LunarLua
This is a separate project from LunaLua, specifically to enhance gameplay and rework for Super Mario Bros. X2R.

# AI Notice
Claude was used in this project for indications of what to program in, but has not been used for putting in obviously-generated code. I wanted to put this in just in case if those who think the code in this is AI-generated, for the most part it's not. Just saying.

## How to compile
You'll need to install the Community version of Visual Studio 2015 to compile this repo.

Just open the "LunaDLL.sln" file on VS2015, then compile. If you want to compile using the batch files, you can do so by double clicking "build_with_pause.bat" once you have installed VS2015.
